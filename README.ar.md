# 📡 نظام كشف وتتبّع الأشخاص بإشارات الواي فاي (Wi-Fi CSI)

نظام **بدون كاميرا** بيستخدم بيانات **Channel State Information (CSI)** من
جهازَي **ESP32** عشان يكتشف وجود شخص في الغرفة، يقدّر مكانه ثنائي الأبعاد
`(x, y)`، ويعرض النتيجة على **خريطة حرارية حيّة** مع عدّاد أشخاص.

> 🇬🇧 English overview and setup: [`README.md`](README.md)

---

## ✨ المميزات

| الميزة | الوصف |
|---|---|
| 📡 **دمج لينكين متعامدين** | لينك أفقي + لينك رأسي → تقدير موقع 2D بدل اتجاه واحد |
| 🔥 **خريطة حرارية حيّة** | تراكم الحركة مع اضمحلال زمني وبلوبات Gaussian |

| 👥 **عدّاد أشخاص** | عدّ Blobs بـ OpenCV؛ الـ ML اختياري ومش بيتحكم افتراضياً |

## ⚙️ كيف يعمل النظام؟

1. كل ESP32 بيبعت ping للراوتر، والراوتر بيرد، والـ ESP32 بيطبع سطر `CSI_DATA`
   لكل حزمة على السيريال (حوالي 25 هرتز).
2. `csi_reader.py` بيفك مصفوفة CSI ويحسب السعة `√(imag² + real²)` لكل subcarrier.
3. `LinkEngine` بيحسب التشتت النسبي وهبوط الـ RSSI ويطلع **نسبة نشاط 0–100%** لكل لينك.
4. `DualLinkFusion` بيحوّل النسبتين لموقع `(x, y)` ويقرر الحضور بالحركة **أو**
   بنافذة سماح محدودة بعد آخر حركة.
5. فلتر **Kalman** بينعّم المسار، مع `max_step` و`deadband` لمنع القفزات والاهتزاز.
6. `HeatmapEngine` بيبني الخريطة الحرارية، وOpenCV بيرسم الخريطة والنقطة والأثر ولوحة HUD.

## 🧰 المتطلبات

| الحاجة | ملاحظة |
|---|---|
| Python **3.10 – 3.12** | متستخدمش 3.14 (ممكن OpenCV ميكونش له wheels جاهزة) |
| 2 × ESP32 DevKit v1 | أي ESP32 كلاسيكي به واي فاي |
| راوتر أو هوت سبوت **2.4 GHz** | ESP32 لا يدعم 5 GHz |
| كابل USB + درايفر CP2102/CH340 | واحد لكل بورد |

## 🚀 البدء السريع

### 1) تثبيت المكتبات

```bat
python -m venv CSI\.venv
CSI\.venv\Scripts\activate
pip install -r CSI\requirements.txt
```

### 2) تشغيل المحاكاة (بدون هاردوير)

```bat
python CSI\src\dual_link_tracker.py --demo
```

أو دبل كليك على **`run_tracker_demo.bat`**.

> الديمو: شخص بيمشي 33 ثانية، وبعدها الغرفة تفضل فاضية 12 ثانية عشان تشوف
> الحضور بيرجع `NO` ويثبت.

```bat
python CSI\src\scope_monitor.py --demo
```

### 3) التشغيل الحقيقي

```bat
python CSI\src\dual_link_tracker.py --port1 COM8 --port2 COM9
```

أو حدّد البورتات مرة واحدة في `CSI\config.json` وشغّل:

```bat
python CSI\src\dual_link_tracker.py
```

### الأزرار في نافذة المتتبع

| الزر | الوظيفة |
|---|---|
| `C` | إعادة معايرة الخلفية (سيب الغرفة فاضية) |
| `Z` / `R` | مسح الخريطة الحرارية / إعادة ضبط |
| `+` / `-` | تعديل عتبة الكشف |
| `Q` / `Esc` | خروج |

## 🔧 تركيب الهاردوير

1. **احرق الفيرموير** — سكتشات Arduino في
   [`CSI/firmware_arduino/`](CSI/firmware_arduino/README.md)، ونسخة ESP-IDF في
   [`CSI/firmware/`](CSI/firmware/README.md).
2. **رتّب الأجهزة** — الراوتر في مكان ثابت، وESP32 #1 و#2 بحيث يكون اللينكين
   **متعامدين تقريباً** وبيقطعوا منطقة الاهتمام (مسافة أكبر من متر من الراوتر).
3. **حدّد البورتات** — من `devices[].port` في `CSI/config.json` أو بـ
   `--port1/--port2`. لمعرفة البورتات:
   ```bat
   python CSI\src\main.py --list-ports
   ```
4. **اعمل معايرة** — شغّل والغرفة فاضية ~3 ثوانٍ، وبعدها اتحرك. اضغط `C` لو
   البيئة اتغيرت.

## 🔐 الفيرموير وبيانات الواي فاي

بيانات الشبكة **مش مكتوبة في الكود**. كل سكتش بيقرأ من `secrets.h` محلي
ومستثنى من Git:

```bat
cd CSI\firmware_arduino\csi_scope_esp32
copy secrets.h.example secrets.h
```

وبعدين عدّل:

```c
const char* PRIMARY_SSID = "YOUR_SSID";
const char* PRIMARY_PASS = "YOUR_PASSWORD";
```

كرر نفس الخطوة في `csi_scope_esp32_2/`.

> 🔒 لو البيانات دي اترفعت على Git قبل كده، **غيّر الباسورد**؛ إزالتها من تاريخ
> Git محتاجة إعادة كتابة (rewrite).

## 🎛️ الإعدادات

كل إعدادات المتتبع في `CSI/config.json` → `tracker`:

| الإعداد | الافتراضي | المعنى |
|---|---|---|
| `threshold` | `50.0` | نسبة النشاط المطلوبة لاعتبارها حركة |
| `stationary_hold_sec` | `10.0` | نافذة السماح بعد آخر حركة |
| `static_shadow_db` | `1.5` | هبوط RSSI اللي يُعتبر ظل جسم (بيضاعف النافذة) |
| `calibration_seconds` | `3.0` | مدة معايرة الغرفة الفاضية |
| `smoothing_alpha` | `0.35` | نعومة حركة النقطة |
| `max_step` | `0.065` | أقصى خطوة لكل إطار (منع القفز) |
| `deadband` | `0.016` | أقل حركة قبل تحديث النقطة |
| `heat_decay` | `0.978` | اضمحلال الخريطة الحرارية |
| `heat_intensity` | `16.0` | قوة تراكم الحرارة |
| `kalman_process_noise` | `0.10` | ضوضاء العملية `Q` |
| `kalman_measurement_noise` | `0.001` | ضوضاء القياس `R` |

وأيضاً في قسم `processing`:

| الإعداد | الافتراضي | المعنى |
|---|---|---|
| `count_ml_override` | `false` | السماح للـ ML باستبدال عدّ الـ blobs |
| `count_ml_confidence_min` | `0.6` | أقل ثقة مطلوبة للاستبدال |

> أي قيمة من سطر الأوامر (`--threshold` / `--hold` / `--shadow`) بتتغلّب على
> `config.json`.

## 🧠 الموديل والـ ML

`count_model.py` بيبني متجه 11 خصيصة لكل نافذة (متوسط/انحراف/أقصى النشاط
ومتوسط هبوط RSSI لكل جهاز + الإجماليات + معدل الحضور)، و`RandomForestClassifier`
بيتوقع عدد الأشخاص.

```bat
:: فحص سريع ببيانات صناعية
python CSI\train_count_model.py --synthetic

:: تدريب على بيانات حقيقية (اجمعها الأول)
python CSI\collect_count_data.py --count 1 --seconds 60
python CSI\train_count_model.py --csv CSI\count_data.csv
```

حمايات مهمة:

- السكربت **بيرفض يحفظ** الموديل لو كل الصفوف بنفس الـ label (موديل بفئة واحدة
  عديم الفائدة).
- ملفات CSV قديمة بأسماء أعمدة مختلفة (مثل `left_*`/`right_*`) بتترتب بالترتيب
  مع تحذير.
- `--out-dir` بيسمح بالتدريب في مجلد منفصل من غير ما تلمس الموديل الحالي.

> ⚠️ الموديل المرفق متدرّب على بيانات **شخص واحد** فقط، عشان كده هو **مساعد**
> ومتعطّل كـ override افتراضياً. عدّ الـ blobs هو المصدر الرسمي لحد ما تجمع
> بيانات متعددة الفئات وتعيد التدريب.

## ⚠️ حدود النظام (بصراحة)

- **كشف حركة بالأساس.** الشخص الساكن تماماً بيتمسكه لنافذة سماح محدودة، مش
  للأبد. كشف التنفس محتاج معالجة متخصصة.
- **العمق تقريبي.** لينكين بيقدّروا يمين/شمال كويس، لكن قريب/بعيد تقديري.
  التحديد 2D الدقيق والعدّ المتعدد يحتاج **3–4 أجهزة** أو موديل متدرّب.
- **البيئة بتأثر.** الأثاث والحيطان والأشخاص التانيين وشبكات الواي فاي المجاورة.
- **الخريطة الحرارية توضيحية** مش مقياس هندسي دقيق.
- **الاختبارات الحالية** ديمو/وحدات، ومش بديل عن تجربة هاردوير حقيقية.

## 🐞 استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| `cannot open COM3` | اتأكد من الكابل/الدرايفر، اقفل أي برنامج سيريال تاني، جرّب `--list-ports` |
| مفيش سطور CSI | شبكة 2.4 GHz، راجع `secrets.h`، اتأكد إن البورد واخد IP |
| النافذة مش بتظهر | ثبّت OpenCV: `pip install opencv-python` |
| النقطة بترعش | زوّد `smoothing_alpha` / `deadband` أو علّي `threshold` |
| مفيش كشف | قلل `threshold` واعمل معايرة `C` والغرفة فاضية |
| الحضور مش بيرجع `NO` | قلل `stationary_hold_sec` أو علّي `static_shadow_db` |
| تأخير/فقدان إطارات | قلل `CONFIG_SEND_FREQUENCY` في الفيرموير وأعد الحرق |
